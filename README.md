# Global Green Energy Report 2026

## Project Brief
This is a single page technical report about global green energy sources. 
it covers solar, wind and geothermal energy showing their efficiency 
and growth rates in 2025. the page was built using semantic HTML5 tags 
to make it accessible and SEO friendly.

## Technologies Used
- HTML5

## Features
- Semantic HTML structure using header, nav, main, article, section and footer
- Navigation menu with internal anchor links
- Heading hierarchy using h1, h2 and h3 tags
- Data table with caption, thead and tbody
- Key takeaways unordered list
- Responsive and readable layout
- SEO meta tags in the head section

## Sections
1. Executive Summary - overview of green energy in 2025
2. Annual Growth - growth drivers and regional highlights
3. Resource Types - solar, wind and geothermal breakdown
4. Comparison Data - table showing efficiency and growth stats
5. Key Takeaways - summary points in unordered list

## Data Table
the table compares three energy sources:
- Solar - 22% efficiency, +15% growth
- Wind - 45% efficiency, +10% growth
- Geothermal - 90% efficiency, +2% growth

## Setup Instructions
1. Clone the repository
2. Open index.html in your browser
3. No installation needed

## Business Rationale
Green energy is one of the most important topics of our time. 
this report presents the data in a clean structured format 
so readers can quickly understand which energy sources are 
growing and which are most efficient.
